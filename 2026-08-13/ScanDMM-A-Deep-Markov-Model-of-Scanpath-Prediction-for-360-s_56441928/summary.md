# 论文速读：ScanDMM-A-Deep-Markov-Model-of-Scanpath-Prediction-for-360-s

## 一句话总结
论文提出了一种基于深度马尔可夫模型（DMM）的360°图像扫描路径预测方法ScanDMM，通过语义引导的转移函数和状态初始化策略，建模人类视觉工作记忆驱动的时间依赖注意力动力学，在四个360°图像数据集上达到最优性能，并成功迁移到显著性检测与图像质量评估任务。

## 研究问题与动机
1. **360°图像扫描路径预测的时间依赖性建模不足**：现有方法多为静态显著性图采样或生成式模型，未能完整建模注视行为的时序依赖关系。
2. **现有方法的两大缺陷**：显著性驱动方法（如SaltiNet）产生不稳定、大范围跳变的扫描路径；生成模型（如ScanGAN）对兴趣区域关注度不足且训练不稳定。
3. **起始观看点对扫描路径影响显著但被忽视**：神经科学研究表明，先验历史、场景语义与视觉工作记忆共同引导注意力，而现有模型简单将初始状态设为零向量或随机向量。
4. **小数据集上的过拟合风险**：360°图像数据库规模有限，确定性模型（如RNN）容易过拟合，缺乏概率建模能力。

## 核心贡献（创新点）
1. **首次将深度马尔可夫模型引入360°扫描路径预测**：通过维持和更新视觉状态模拟视觉工作记忆，与已有确定性RNN方法形成本质区别。
2. **提出语义引导的转移函数**：利用S-CNN提取场景语义并结合CoordConv，建模场景语义对视觉工作记忆的干预，区别于以往仅依赖前一时刻状态的做法。
3. **设计基于起始点的状态初始化策略**：用真实起始注视点初始化视觉状态而非零/随机向量，使模型能分配特定起始点，支持图像质量评估等可控生成任务。
4. **展示强泛化能力**：将扫描路径预测模型迁移至显著性检测和360°图像质量评估两个下游任务，证明概率动态建模的普适价值。

## 方法详解
- **生成过程建模**：定义视觉状态序列z_{1:T}编码时间依赖的注意力景观，生成过程由转移函数p_θt(z_t|z_{t-1})和发射函数p_θe(x_t|z_t)构成，通过最大化对数似然训练。
- **证据下界损失**：采用变分推断近似后验p_θ(z|x)，损失函数为重构项（发射概率期望）减去KL散度正则项（推断分布与先验转移分布的差异）。
- **状态初始化**：z_0 = F(ẑ_0, x_1)，其中ẑ_0为可学习参数，F为线性网络，利用真实起始点x_1引导初始状态。
- **转移函数设计**：先通过W_z^t(z_{t-1}⊕ŝ)+b_z^t计算潜在注视分布，再引入类似LSTM的门控机制α_t = σ(W_α^t z_{t-1}+b_α^t)自适应决定历史信息保留比例，最终μ_t^z = α_t ẑ_t + (1-α_t)z_{t-1}，σ_t^z由非线性变换得到。
- **发射函数**：从三维高斯分布N(μ_t^x, σ_t^x)采样注视点，均值和方差均由当前视觉状态z_t经线性变换得到。
- **推断网络**：使用RNN编码未来观测序列x_{t:T}得到隐藏状态H(x_{t:T})，与前一状态结合后输出变分分布参数。

## 实验与结果
- **数据集**：Sitzmann（22图像/1980扫描路径）、Salient360!（85图像/3036路径）、AOI（120图像/随机抽取）、JUFE（206图像/随机抽取），均按1Hz采样。
- **评估指标**：LEV（Levenshtein距离，越小越好）、DTW（动态时间规整，越小越好）、REC（回归测度，越大越好），以及人类一致性和随机游走基线。
- **主要结果**：在四个数据集上均超越ScanGAN、SaltiNet、DeepGaze III等基线；Salient360!上LEV=37.272（优于ScanGAN的38.932）、REC=3.576（最优）；AOI上LEV=12.127、REC=4.024。
- **效率优势**：模型仅18.7MB（约为SaltiNet的1/5），生成1000条扫描路径仅需0.737秒，显著快于ScanGAN（0.987秒）。
- **消融验证**：移除语义引导或状态初始化均导致性能下降，两者结合效果最佳。

## 相关工作脉络
1. **SCANPATH预测的两大流派对比**：显著性驱动方法（CLE、SaltiNet）依赖预计算显著图，本文方法通过概率状态转移直接建模注意力动力学，不依赖外部显著图。
2. **生成模型方法差异**：ScanGAN使用S-CNN和CoordConv生成扫描路径但为确定性GAN框架，ScanDMM采用概率DMM可学习不确定性并提供可控起始点。
3. **2D扫描路径模型的迁移局限**：DeepGaze III、CLE等2D方法将360°图像视为普通图像导致大范围跳变，本文方法专门针对球面投影畸变设计。
4. **视觉注意力的神经科学建模**：受Guided Search 6.0启发，本文显式建模视觉工作记忆的状态转移，区别于纯数据驱动的序列模型。
5. **图像质量评估中的观看行为建模**：将扫描路径预测与IQA结合，利用状态初始化策略模拟不同观看条件，区别于传统无时序感知的IQA方法。

## 局限性与未来方向
1. **仅针对静态360°图像**：未充分考虑动态360°视频的时间连续性问题，但作者指出可拓展至视频场景。
2. **下游应用较为简单**：显著性检测和IQA中仅将生成的扫描路径直接后处理，未针对具体任务设计专用模块。
3. **数据库规模有限**：360°眼动数据稀缺，可能限制模型对复杂场景的泛化能力。
4. **未来方向**：可扩展至动态360°视频、VR传输优化、自动 cinematography、导航与虚拟场景设计等应用。

## 研究启发与可借鉴点
1. **概率状态空间建模值得迁移**：DMM架构可用于其他视觉时序任务（如视频注意力预测、GUI交互轨迹生成），其门控转移机制可借鉴。
2. **起始点初始化策略具有通用价值**：在需要可控生成的任务（如IQA、推荐系统）中，用条件信息初始化隐状态可提升任务适配性。
3. **语义引导的状态转移设计**：将场景上下文与历史状态融合的门控机制，可推广至任意序列生成任务。
4. **跨任务泛化验证思路**：同一模型同时服务扫描路径预测、显著性检测、质量评估三个任务，为模型通用性评估提供范式。
5. **评估指标的人机对比基线**：使用human consistency作为性能上界，为生成模型评估提供更合理的参照。

## 关键术语表
- **Scanpath**：视觉扫描路径，指观看过程中一系列注视点的时序序列。
- **Deep Markov Model (DMM)**：深度马尔可夫模型，结合深度学习与状态空间模型的变分推理框架。
- **Visual Working Memory**：视觉工作记忆，指短暂保持和操作视觉信息的认知机制，本文建模为隐状态序列。
- **S-CNN**：球面卷积神经网络，专为360°图像设计的卷积架构，避免等距柱状投影畸变。
- **CoordConv**：坐标增强卷积，向卷积操作引入输入坐标信息，增强空间位置感知。
- **Evidence Lower Bound (ELBO)**：证据下界，变分推断中用于近似后验分布的目标函数下界。
- **Human Consistency**：人类一致性，用不同被试组间扫描路径相似度作为模型性能的理论上界。

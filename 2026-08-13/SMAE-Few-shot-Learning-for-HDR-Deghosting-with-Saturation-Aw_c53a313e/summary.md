# 论文速读：SMAE-Few-shot-Learning-for-HDR-Deghosting-with-Saturation-Aw

## 一句话总结
本文提出双阶段半监督少样本HDR去鬼影框架SSHDR，通过将饱和区域类比为掩码训练自监督饱和掩码自编码器（SMAE）恢复基础曝光内容，再利用自适应伪标签选择策略迭代消除鬼影，仅需≤5张标注样本即可生成高质量HDR图像。

## 研究问题与动机
- HDR去鬼影的深度学习主流方法高度依赖海量带GT标注数据，但获取无鬼影HDR真值需绝对静止背景与繁琐的人工校验，数据收集成本极高。
- 现有少样本方法（如FSHDR）试图同时处理饱和与鬼影，在标注极少时极易过拟合，且光流合成的动态LDR输入会引入分布偏移，进一步恶化性能。
- 饱和区域（过曝/欠曝）与运动错位区域在信号特性上存在强耦合，联合优化难以收敛至全局最优，需要解耦处理策略。
- 如何在不依赖大量标注的前提下，让模型先学会重建HDR辐射场，再在少量标注引导下迭代去鬼影，是本文要解决的核心问题。

## 核心贡献（创新点）
- 提出SMAE自监督预训练机制，首次将HDR成像中的饱和退化等价于视觉掩码，通过75%高比例随机掩码重建实现无监督鲁棒表示学习。
- 设计样本质量驱动的迭代半监督精调框架，将内容恢复与鬼影去除严格解耦，避免少样本下联合优化导致的过拟合与次优陷阱。
- 提出自适应伪标签选择策略（APSS），利用有标签样本的重投影损失分位数动态设定阈值，线性衰减含饱和/鬼影劣质量伪标签权重，防止错误监督信号干扰训练。
- 在Kalantari、Hu等数据集的1-shot/5-shot及跨数据集设定上达到SOTA，零样本与少样本设定下均超越全监督基线方法。

## 方法详解
- **数据配置**：使用N个无标签动态LDR序列（每序列3张不同曝光）、M=5个静态有标签样本、K≤5个动态有标签样本，构成半监督训练集。
- **第一阶段（SMAE自监督预训练）**：
  - 以短曝光帧为基准，通过曝光调整公式 $X_{i'}^U = clip((X_1^U)^\gamma \times t_i / t_1)^{1/\gamma}$ 模拟中/长曝光LDR，并与gamma校正后的HDR域图像拼接为6通道输入。
  - 将输入划分为8×8非重叠patch，以75%比例随机掩码。模型经特征提取、Hallucination Module（多曝光patch间Cross-Attention补全）与Multi-Scale Residual Swin Transformer Module（MSRSTM，含2×2/4×4/8×8多尺度窗口）输出预测HDR。
  - 自监督损失：将预测HDR映射回三曝光LDR域 $\hat{Y}_i = (\hat{Y} \times t_i)^{1/\gamma}$，与由短曝光GT生成的对应曝光真值计算L1损失：$L_{SSL} = \sum_{i=1}^3 ||\hat{Y}_i - X_i^{GT}||_1$。
- **第二阶段（迭代半监督去鬼影）**：
  - 微调：在少量动态+静态标注数据上微调，经μ-law色调映射 $T(x)=\log(1+\mu x)/\log(1+\mu)$（μ=5000）后，计算重建损失与VGG19感知损失：$L_{fine} = L_{recon} + \lambda L_{percep}$（λ=1e-2）。
  - APSS伪标签筛选：用当前模型预测有标签HDR，映射至中曝光LDR并在良好曝光区域计算重投影损失，取85分位数作为阈值τ_t。对无标签样本同理计算损失，若超限则按 $W_{t+1}^{U_i} = (m_t^U - L_{select,t}^{U_i})/(m_t^U - \tau_t)$ 线性降权，否则保持1。
  - 迭代训练：每步使用更新后的权重混合有标签与无标签损失 $L_{Iteration} = L_{recon}^D + L_{recon}^S + \sum W^U_i L_{recon}^{U_i} + \lambda(\cdot)$，逐步提升去鬼影能力。

## 实验与结果
- **数据集与设定**：Kalantari’s（74 train/15 test）、Hu’s（85 train/15 test）为主实验集；Tursun’s与Prabhakar’s用于跨数据集泛化评估。评测指标含PSNR-L/μ、SSIM-L/μ、HDR-VDP-2。
- **Kalantari数据集（5-way-5shot）**：PSNR-L 41.54±0.10，PSNR-μ 41.61±0.08，分别超越次优FSHDR约0.15dB与0.21dB；HDR-VDP-2达67.33。
- **Hu数据集（5-way-5shot）**：PSNR-L 47.41±0.12，PSNR-μ 44.24±0.17，超越FSHDR约0.28dB与0.26dB；SSIM与HDR-VDP-2亦居首。
- **1-shot设定**：在两个数据集上均稳定领先，验证了方法在极低标注预算下的有效性。
- **跨数据集泛化**：在零样本（S1）、单样本（S2）及反向交叉评估（S4）中，本文方法在多数指标上超越全监督基线（如ADNet、AHDRNet），证明SMAE预训练赋予的表示具有强迁移性。
- **消融验证**：移除SMAE预训练（Stage2Net）与移除APSS（w/o APSS）均导致PSNR与HDR-VDP-2显著下降，确认双阶段解耦与伪标签加权缺一不可。

## 相关工作脉络
- **FSHDR [22]**：同类少样本HDR去鬼影方法，依赖光流合成动态LDR输入且联合优化饱和/鬼影；本文放弃显式光流合成，改用自监督掩码重建解耦两类退化，避免分布偏移。
- **AHDRNet [31] / ADNet [14]**：基于空间注意力与可变形卷积的全监督去鬼影网络；本文证明将其套入双阶段半监督框架仍可超越原版，凸显预训练+伪标签筛选的增益。
- **Kalantari [9] / DeepHDR [30]**：早期CNN HDR融合代表，依赖密集光流或单应性对齐；本文不依赖显式几何对齐，转而从数据驱动表征中学习隐式融合与恢复。
- **MAE [6]**：视觉掩码自编码开山之作；本文创新地将“饱和即掩码”的成像物理先验引入HDR域，实现无需HDR真值的自监督预训练范式。
- **传统对齐/匹配/拒绝类方法 [3,8,10,24]**：依赖手工特征或能量优化，计算开销大且难处理大运动；本文端到端学习，在极少标注下实现质量反超。

## 局限性与未来方向
- **局限性**：SMAE预训练完全依赖无标签动态序列，若输入存在极端光照剧变或非刚性大形变，重建HDR的结构真实性可能受限；APSS采用固定85分位数阈值，在批次内样本质量跨度极大时鲁棒性存疑。
- **未来方向**：引入时序一致性或3D几何先验约束SMAE重建；设计数据驱动的动态阈值替代固定分位数；将框架扩展至视频HDR重建、多帧超分辨率及低光照成像修复等通用退化恢复任务。
